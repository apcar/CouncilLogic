# Support

Model Council is a public alpha maintained on a best-effort basis. There is no
service-level agreement, guaranteed response time, or production support.

- Read the [README](README.md), [operations runbook](docs/OPERATIONS.md), and
  [security model](docs/SECURITY.md) first.
- Use the bug-report issue form for reproducible defects.
- Use the design-proposal issue form for architecture and research discussion.
- Use GitHub private vulnerability reporting for suspected security issues.

Do not post credentials, private prompts, provider responses, audit databases,
or identifying data. Questions about provider accounts, billing, model access,
or API availability should go to the relevant provider.

External pull requests and copyrightable contributions are closed as described
in [CONTRIBUTING.md](CONTRIBUTING.md).
